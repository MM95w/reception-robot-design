# Reception & Luggage Service Robot

## Project Overview

Design and development of an indoor Reception & Luggage Service Robot for a university engineering project.

The robot is designed from scratch with a focus on:

- Mechanical design
- Manufacturability
- Modularity
- Maintenance
- Component integration
- ROS2 compatibility
- Gazebo simulation

## Main Specifications

| Parameter | Target |
|---|---|
| Overall height | ~1500 mm |
| Base length | 750 mm |
| Base width | 400 mm |
| Base height | ~400–500 mm |
| Drive wheels | 2 × Ø200 mm |
| Caster wheels | 2 |
| Payload | 20–30 kg |
| Battery | 260 × 160 × 135 mm |
| LiDAR | RPLIDAR A1M8 |
| Camera | CSI IMX519 |
| Display | 10.1-inch Waveshare HDMI LCD |
